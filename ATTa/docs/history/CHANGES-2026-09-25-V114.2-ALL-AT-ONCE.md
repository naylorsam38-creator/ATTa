# v114.2 — every app at once, script probe instead of the LLM

## Every app at the same time (app_runner.py)
- `APP_BUILDER_RUN_PARALLEL` now defaults to 0 = every app starts together. A number still caps it.
- Removed: the memory start gate (`START_FREE_MEMORY`, `_wait_for_memory`), the disk start gate
  (`START_FREE_DISK_GB`), and the download queue (`MAX_DOWNLOADS`, `_DOWNLOAD_SLOTS`). Nothing waits.
- Kept (they end or contain an app, they don't hold others up): per-app memory cap (`APP_MEMORY_SHARE`),
  host memory floor stop (`HOST_MEMORY_FLOOR`), per-app attempts (`MAX_ATTEMPTS`) and time budget,
  settle/warm-up rechecks, the Docker Hub rate-limit wait, and the second pass for apps that failed
  only because the machine ran out.

## Script probe replaces the LLM tier when the LLM is off (maintenance.py)
- Tier 3 with no API key / `APP_BUILDER_HEAL_LLM_PER_DAY=0` = `PROBE`: for a failure no known fix
  matches, try each general repair for that layer, one per round, verify after each.
- The repair that clears it is saved as a learned rule under the failure's key (the area, e.g.
  `1 INSTALLED:<code>`), with the app name replaced by `{app}`. Same failure on any app -> tier 1 next time.
- Learned rules still start PENDING and go through rule_lifecycle.py (candidate / confirmed / retired).
- Items fixed while others still fail are learned straight away, not only when the whole layer passes.
- `MAX_ROUNDS` = 3 + longest probe list (8), so every candidate gets tried before a human is alerted.
- To widen coverage: add a general action to `PROBE`.
