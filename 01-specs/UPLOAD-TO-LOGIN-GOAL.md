# Upload-to-Login Goal — Governing Addition

The deployed system must support: browser login -> ZIP upload -> isolated intake -> safe extraction -> live upstream Git fetch into the library -> existing UI/Capability installer -> existing six-stage watcher -> web status -> Front Door.

Rules: do not replace the watcher; do not declare ready from manifests alone; do not guess repositories; do not modify upstream source merely to install the overlay; no mocks, simulations, fake providers, or fabricated success; public URL is incomplete until a real browser login is tested.

AWS account access, DNS, TLS and final public URL require the actual AWS environment and cannot be truthfully marked complete inside this package.
